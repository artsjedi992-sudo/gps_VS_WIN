КЕЦ Карлово GPS - Windows версия

Стартиране:
  KEZ_GPS.exe

ВАЖНО:
Това е x64 версия. За Windows 7 е необходим:
- Windows 7 SP1 x64
- .NET Framework 4.8
- актуализирана Universal CRT поддръжка

HTML интерфейсът е запазен от Android версията.
Excel файлът се зарежда чрез стандартния файлов диалог на Chromium.
